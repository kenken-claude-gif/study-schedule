# テスト勉強プランナー

高校生向けの定期テスト勉強スケジュールアプリ（PWA）。テスト範囲と予定を入れると、勉強の計画を自動で作る。毎日やった量を記録すると、残りの計画が自動で組み直される。

## 機能

| 画面 | できること |
|---|---|
| 今日 | 今日やること（何を・どこからどこまで・目安の時間）、やり方の手順、やった量と×の数の記録、明日以降の分の先取り |
| 計画 | 全体の見通し（必要な時間と使える時間）、教科ごと・周ごとの進み具合、日ごとの計画、省いたもの |
| 範囲 | テストの作成（高1の教科プリセット・前回のテストからコピー）、教科ごとのテスト日・苦手度・前回と目標の点数・教材の範囲、結果の入力 |
| 予定 | 部活・塾・家族の予定（毎週くり返しも可）、入れる前に計画への影響を表示、相談カレンダー、曜日ごとの勉強できる時間帯 |
| 成績 | 定期テスト・模試の結果の入力と推移グラフ（模試は偏差値と得点率を切り替え）、前回からの変化、表での表示 |
| コツ | 勉強法のガイド、予備の割合、1日の教科数、バックアップの保存と復元 |

## スケジューリングの考え方

`src/domain/scheduler.ts` にまとめてある。

- **3周制**：1周目＝全部やる（理解・提出物）／2周目＝×と△だけやり直す／仕上げ＝テスト3日前〜前日
- 1周目は勉強期間の前半までに終わらせる。苦手な教科ほど早めに（苦手5→45%、得意1→55%の地点まで）
- 2周目は1周目が終わった次の日以降（間を空けた方が定着する＝分散学習）
- 2周目の量は、記録した×の数から決まる（記録がないうちは苦手度から見積もる）
- 1日の量は「残りの量÷残りの時間」から出す目安にそろえる（少しだけ前倒し）。勉強できる時間の80%だけ埋めて、残りは遅れを吸収する予備にする
- 1日に扱う教科は3つまで。理想のペースから遅れている教科から順に枠を割り当てるので、自然にローテーションする
- 提出物は提出日の前日までに入れる。遅れているときは1教科が1日を独占しないよう、教科ごとに公平に配る
- 時間が足りないときは、点数につながりにくいもの（得意な教科の仕上げ・提出物でない教科書の読み直しなど）から省いて、苦手な教科の解き直しを残す。何を省いたかは画面に出す（提出物の1周目だけは省かない）
- 1周目が目安より遅れても、解き直しの時間が残るテスト3日前までに終わらせるように急がせる
- 1周目は「どのページをやったか」を範囲で記録する。先取りなど順番どおりでない記録でも、まだやっていないページから計画する

## 開発

Node.js 24 以上が必要。

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

```bash
npm run build
```

- テストは Node 標準の `node:test`（外部のテストライブラリは使っていない）
- 動作確認用に、URL に `?today=2026-11-09` を付けると「今日」の日付を変えられる

## データの保存場所

データは端末のブラウザ（localStorage）にだけ保存され、外部には送信しない。機種変更などに備えて「コツ → バックアップ」で JSON ファイルに保存できる。

## 毎日使うための作り

- アプリを開いたまま日付が変わっても、前面に戻ったときに今日の計画に切り替わる
- Android の戻るボタンで、前のタブに戻る（アプリが閉じない）
- 保存に失敗したとき（空き容量不足など）は画面に警告を出す
- 画面でエラーが起きても真っ白にせず、データをファイルに保存できる画面を出す
- バックアップから戻すときは、ファイルの中身（テスト・教科・教材・記録・模試）の形を確認してから読み込む
- オフライン用に保存したファイルは、新しい版が出たら古い版を消す（端末にたまらない）

## Android で使う

PWA なので、HTTPS で公開したページを Android の Chrome で開き、メニューの「ホーム画面に追加（アプリをインストール）」でアプリとして使える。オフラインでも開ける。

- 公開先の例：GitHub Pages、Cloudflare Pages、Netlify（`dist/` の中身を置くだけ。サーバー側にデータは送られない）
- APK にしたい場合は、Capacitor で `dist/` を包む（Android SDK と JDK が必要）
